Publishes workspace files to a Subversion repository in a single commit.
url
SVN repository URL (target directory must already exist)
credentialsId
Optional Jenkins credential ID (username/password). Empty = anonymous.
source
Ant-style pattern of workspace files, e.g. target/*.jar
target
Optional sub-path inside the repository, e.g. releases/v1.0
commitMessage
Commit message (supports ${BUILD_NUMBER} style environment expansion)
cleanup
Delete target files no longer in the publish set (default false)
